# Анализ продаж и прибыльности Superstore

## О проекте

Проект посвящён анализу продаж и прибыльности розничной компании на основе исторических данных Superstore за 2014–2017 годы.

Цель проекта — выявить ключевые факторы, влияющие на финансовые результаты компании, определить наиболее и наименее прибыльные категории товаров, а также оценить взаимосвязь между размером скидок и прибыльностью продаж.

В рамках проекта выполнен анализ данных с использованием Python и разработан интерактивный дашборд в Power BI.

## Бизнес-задачи

- Оценить общие показатели продаж и прибыльности компании.
- Определить наиболее прибыльные и убыточные категории и подкатегории товаров.
- Проанализировать влияние скидок на финансовые результаты.
- Выявить товары с наибольшими убытками.
- Разработать интерактивный дашборд для мониторинга ключевых показателей бизнеса.

## Используемые инструменты

- **Python** — обработка и анализ данных.
- **Pandas** — очистка, группировка и агрегирование данных.
- **Matplotlib** — визуализация результатов анализа.
- **Jupyter Notebook** — среда выполнения анализа.
- **Power BI** — создание интерактивного аналитического дашборда.

## Данные

В проекте использован открытый набор данных Superstore.

Основные характеристики:
- Период: 2014–2017 годы.
- Количество записей: 9 994.
- Количество уникальных заказов: 5 009.
- Количество уникальных клиентов: 793.
- Пропущенные значения и полные дубликаты отсутствуют.

В наборе представлены сведения о заказах, клиентах, товарах, категориях, скидках, продажах и прибыли.

## Этапы работы

### 1. Первичный анализ и подготовка данных

- Загрузка исходного CSV-файла.
- Изучение структуры и типов данных.
- Проверка пропущенных значений и дубликатов.
- Преобразование дат в формат datetime.
- Подготовка очищенного набора данных для дальнейшего анализа.

### 2. Анализ продаж и прибыльности с помощью Python

Рассчитаны ключевые бизнес-показатели:
- Общая выручка.
- Общая прибыль.
- Количество заказов и клиентов.
- Объём проданных товаров.
- Рентабельность продаж.

Проведён анализ:
- продаж и прибыли по категориям и подкатегориям;
- прибыльности товаров;
- зависимости финансовых результатов от размера скидок;
- наиболее убыточных товарных позиций.

### 3. Создание дашборда в Power BI

На основе подготовленных данных разработан интерактивный дашборд, включающий:

- KPI-карточки с основными показателями бизнеса;
- динамику продаж и прибыли по месяцам;
- анализ прибыли по категориям товаров;
- анализ прибыли в зависимости от размера скидки;
- сравнение прибыльности подкатегорий;
- таблицу 10 наиболее убыточных товаров;
- фильтры по региону, сегменту клиентов, категории и периоду.

## Основные результаты анализа

По результатам исследования получены следующие показатели:

| Показатель | Значение |
|---|---:|
| Общие продажи | $2,297,200.86 |
| Общая прибыль | $286,397.02 |
| Количество заказов | 5,009 |
| Количество клиентов | 793 |
| Проданное количество товаров | 37,873 |
| Рентабельность продаж | 12.47% |

### Ключевые наблюдения

**1. Различия в прибыльности категорий**

Категория Technology показала наибольшую прибыль — $145,454.95, а её рентабельность составила 17.40%.

При этом категория Furniture обеспечила продажи на сумму $741,999.80, но её рентабельность оказалась значительно ниже — 2.49%.

**2. Убыточные подкатегории**

Наибольшие убытки выявлены в подкатегории Tables: убыток составил $17,725.48, а рентабельность — −8.56%.

Также отрицательный финансовый результат показали Bookcases и Supplies.

**3. Связь скидок и прибыльности**

В агрегированных данных наблюдается отрицательная прибыльность при уровнях скидок от 30% и выше.

Наибольшие убытки связаны с отдельными позициями, продававшимися с высокими скидками. Это указывает на необходимость более детального контроля скидочной политики.

**4. Убыточные товары**

Выявлены товары с существенными отрицательными финансовыми результатами. В частности, Cubify CubeX 3D Printer Double Head Print принёс убыток $8,879.97.

## Практические рекомендации

На основании результатов анализа можно предложить следующие направления для дальнейшей работы бизнеса:

- Пересмотреть скидочную политику и оценивать её влияние на прибыльность, а не только на объём продаж.
- Провести дополнительный анализ причин убыточности подкатегорий Tables и Bookcases.
- Оценить целесообразность дальнейшего продвижения товаров с устойчиво отрицательной прибылью.
- Использовать интерактивный дашборд для регулярного мониторинга ключевых показателей продаж и прибыльности.
